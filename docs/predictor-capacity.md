Generated by `training/predictor_capacity.py` on 2026-11-12. Same data as [probe-results.md](probe-results.md): 4157 LLMRouterBench prompts, Qwen3.5-9B layer 18 last-token activations (4096 dims), the same 3325 / 832 train / test split.

Only the success predictor changes between rows. Each family's settings (regularization, depth) are chosen by 5-fold cross-validation on the training split, scored by within-benchmark AUROC, as for the shipped probe. Then the chosen model is refit on the whole training split and scored once on the test split.

- **Learned parameters:** numbers fitted to the success labels (PCA is fitted without labels and not counted).
- **AUROC:** tier prediction vs. each member model's success. **Within:** the same inside each benchmark, averaged; ranking difficulty beyond recognizing the benchmark.
- **Train − test gap:** within-benchmark AUROC on the training data minus on the test data; large gaps mean memorization.
- **Routing:** opas's weighted scoring on the test split (token predictions are the shipped ridge heads for every row). *Random* is random routing at the same mean cost.
